# Wariant 1 — oficjalny DJI SDK

Ten moduł jest przeznaczony dla modelu znajdującego się na aktualnej oficjalnej liście DJI Mobile SDK. `DJI Mini 2 SE` nie jest przez ten adapter uznawany za obsługiwany.

W projekcie Android należy dodać oficjalny artefakt DJI SDK zgodnie z licencją DJI i uzupełnić `OfficialDjiSdkControl.kt` wyłącznie dla potwierdzonego modelu. Nie należy wysyłać komend do RC-N1 przez prywatny protokół.
